# 문서 규칙

- `PRD-MarkPad.md`: 요구사항 ID(F-xxx-nn)와 우선순위는 사용자 승인 없이 바꾸지 않는다. 결정은 §9 결정 기록에 날짜와 함께 추가.
- `ARCHITECTURE.md`: 코드와 불일치를 발견하면 문서를 수정하되, 변경 이유를 `docs/ADR/ADR-nnn-*.md`에 남긴다. 부록 A(가정 목록)는 확인 결과를 "확인됨/수정됨(→ADR-nnn)"으로 표기.
- `IMPLEMENTATION-PLAN.md`: 작업 표의 DoD는 완화하지 않는다. 작업을 쪼개야 하면 `T-28a`, `T-28b`처럼 하위 ID를 만든다.
- `STATUS.md`: 형식을 유지한다(진행 중 1개, 완료 목록, 막힌 항목, 다음 작업). 세션 종료 시 반드시 갱신.
- 문서는 한국어, 코드 식별자·API 이름은 원문.
